## Security Concern (reported, not exploited)

The project directory sits inside the user's **Desktop**, which contains many
personal and university documents (resumes, transcripts, APS files, credentials,
recommendation letters, and similar) in the same parent folder.

Two consequences for the build:
1. All future tooling under ATLAS-X must scope `read`/`search`/`glob` operations
   to the project root and never walk up to the Desktop or `$HOME`.
2. Nothing generated by ATLAS-X may write outside the project; sandbox and
   artifact-store boundaries must be enforced accordingly (Phases 3, 4, 5).

No private content was read, copied, or recorded in producing this report.
